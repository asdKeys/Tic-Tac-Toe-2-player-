# [2 Player]Tic-Tac-Toe

## About

This is 2 player tic-tac-toe. Just follow the instructions on how to run it below and 1v1 anyone you want!

## How to Run

Looking at the screenshots isn't nearly as cool as trying it out yourself on this one so just go to https://www.onlinegdb.com/online_python_compiler#, then scroll up and double click the file called "main.py". Then, copy and paste that code into the python compiler. To run the code properly, you must click the drop-down arrow next to the run button and then press "Run with display screen(beta)" as demonstrated in the screenshot below. If the display screen takes more than 20 seconds to connect or something goes wrong, just refresh and try again.

Since there can be infinite rematches the scoreboard must always update and always be accurate because with rematches even tic-tac-toe could get competitive. That's why we have a scoreboard. This screenshot shows the scoreboard a few matches later.
